About the project

Textile waste is still sorted by hand, which is slow and error-prone. EcoTex Sorter is an AI-based system that classifies fabric images so recycling can start from the right material.

How it works

The image is resized to 224×224 and passed to a MobileNetV2 model (transfer learning, TensorFlow/Keras). The model returns a probability for each fabric, and the web app (Flask) shows the top three with a recycling tip.

Limitations

  • Works best on close-up, well-lit photos of a single fabric.
  • Blended fabrics (for example cotton-polyester) are not supported yet.
  • Identifying material from an image alone is hard, so low-confidence results ask you to retake the photo.
